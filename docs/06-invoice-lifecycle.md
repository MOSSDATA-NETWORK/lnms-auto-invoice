# 账单配置与账单生命周期

## 1. 账单配置

账单配置决定：

- 合并出账的合同计费项。
- 客户、公司、抬头和付款账户。
- 模板、语言、币种和税务策略。
- 周期、账单日、到期日和编号规则。
- 自动生成、自动提交审核和自动发送。
- 收件人、抄送人、明细分组和排序。

推荐始终按账单配置生成。按客户、公司、合同或业务生成是筛选和批量创建配置的辅助入口。

## 2. 多账单示例

```text
客户 A / A 网络科技有限公司

香港带宽账单
  - 香港 IP Transit / 95 带宽费
  - 香港 BGP / 接入费
  - CNY / bandwidth-95-zh

日本托管账单
  - 日本服务器 / 托管费
  - 日本服务器 / IPv4 费
  - USD / colocation-en

一次性费用账单
  - 安装费
  - 调试费
  - 手工生成
```

## 3. 重复计费检测

保存配置、启用配置、生成批次和正式化时检查：

- 一个计费项存在多个有效 `CHARGE`。
- 百分比分摊合计不是 100%。
- 固定分摊超过原金额。
- `DISPLAY_ONLY` 被计入应收。
- 计费项没有自动账单配置。
- 计费项和配置的客户、公司或币种冲突。

## 4. 模板优先级

```text
预览手工指定
  -> 账单配置
  -> 合同计费项
  -> 业务
  -> 业务分组
  -> 合同
  -> 公司
  -> 客户
  -> 币种与语言默认
  -> 系统默认
```

同一优先级多重命中属于配置错误。

## 5. 预览状态

```text
GENERATING -> DRAFT -> BUSINESS_REVIEW -> FINANCE_REVIEW -> APPROVED
     |          |             |                |
     v          v             v                v
   ERROR      VOIDED        REJECTED         REJECTED

APPROVED -> FINALIZING -> FINALIZED
```

## 6. 正式账单状态

文档状态：

```text
FINALIZING -> CONFIRMED -> SENT -> VOIDED -> REPLACED(optional)
```

付款状态独立：

```text
UNPAID -> PARTIALLY_PAID -> PAID
   |              |
   +-> OVERDUE <--+
```

文档、发送和付款状态分开保存，避免组合状态爆炸。

## 7. 预览生成

1. 锁定账单配置和账期。
2. 选择有效计费项和分摊。
3. 检查合同、价格、币种和重复归属。
4. 同步或选择用量快照。
5. 运行纯计费引擎。
6. 创建明细、计算快照和异常。
7. 解析模板并生成水印 PDF。
8. 进入 `DRAFT` 或 `ERROR`。

## 8. 编辑与重新计算

允许：重新同步、重新计算、更换模板、添加调整、排除系统明细、修改备注和排序。

系统明细不允许直接覆盖成无来源的人工金额：

- 排除使用 `preview_exclusion`。
- 金额变更使用 `preview_adjustment`。
- 重算替换系统明细，保留仍有效的调整和排除意图。

## 9. 审批失效

以下变化递增预览版本并清除已有审批：

- 金额、税额、账期、币种、汇率或到期日。
- 用量快照、计费项、调整或排除项。
- 模板版本、付款账户、抬头和客户可见备注。

## 10. 两级审批

第一阶段：

```text
业务审核 -> 财务审核 -> APPROVED
```

- 业务审核检查用量、服务、合同和来源。
- 财务审核检查价格、税、调整、抬头和付款条件。
- 阻断异常不能通过。
- 超权限调整追加高级审批。
- 审批记录绑定预览版本。

## 11. 正式化

数据库事务内：

1. 锁定已批准预览。
2. 校验审批版本和阻断异常。
3. 通过 `source_preview_id` 检查幂等。
4. 分配正式编号。
5. 复制并冻结账单、明细、调整、快照和模板版本。
6. 创建 `FINALIZING` 正式账单。
7. 写入 `InvoiceFinalizationRequested` Outbox。

Render Worker：

1. 使用冻结数据和模板渲染。
2. 生成 PDF、SHA-256 和文件记录。
3. 保存渲染器、Chromium 和字体版本。
4. 账单进入 `CONFIRMED`，预览进入 `FINALIZED`。

渲染失败时保持 `FINALIZING` 并安全重试，不重新编号。

## 12. 编号

预览示例：`PRE-202607-CUST-0001-01`。

正式规则示例：

```text
INV-{YYYYMM}-{CUSTOMER_NO}-{SEQ}
INV-{COMPANY_CODE}-{YYYYMM}-{SEQ}
HK-{YYYYMM}-{SEQ}
```

号码分配使用数据库原子计数器。已分配号码不回收。

## 13. 冻结内容

- 客户、公司、抬头、账期、到期日和时区。
- 用量快照、价格规则和计算快照。
- 币种、汇率、税、折扣和调整。
- 模板版本、资源、列表配置和备注。
- 审批记录、正式化操作者和时间。
- PDF、文件元数据和 SHA-256。

## 14. 作废与更正

```text
正式账单
  -> 作废申请和付款检查
  -> VOIDED
  -> 复制新预览
  -> 修改并重新审核
  -> 新正式账单
  -> REPLACES 关系
```

已有付款时必须先解除分配、退款或完成财务冲销。
